# Controle de Gastos 💸

Aplicação web simples para registrar e visualizar gastos pessoais. Desenvolvido com Flask, HTML, CSS e JavaScript.

## Funcionalidades
- Adicionar, visualizar e excluir gastos
- Tabela responsiva com animação de exclusão
- Mudança de cor do valor restante para alertar risco de individamento (verde, amarelo e vermelho)
- Interface adaptada para celular e desktop

## Tecnologias usadas
- Python + Flask
- HTML5 + CSS3
- JavaScript

## Como rodar localmente
```bash
pip install -r requirements.txt
python app.py
