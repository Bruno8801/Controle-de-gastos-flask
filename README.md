# Controle de Gastos 💸

Aplicação web simples para registrar e visualizar gastos pessoais. Desenvolvido com Flask, HTML, CSS e JavaScript.

## Funcionalidades
- Adicionar, visualizar e excluir gastos
- valor restante com alerta de cor para limites e controles de gastos (verde, laranja e vermelho)
- Tabela responsiva com animação de exclusão
- Interface adaptada para celular e desktop

## Tecnologias usadas
- Python + Flask
- HTML5 + CSS3
- JavaScript

## Como rodar localmente
```bash
pip install -r requirements.txt
python app.py
